# Проверка MyFences 1.0.1

## Исправление невидимых блоков

Исходный smoke-тест 1.0 проверял HWND и off-screen WPF-рендер, но пропустил отсутствие пикселей на рабочем столе. После жалобы пользователя реальный снимок подтвердил дефект.

В 1.0.1 вместо cross-process SetParent используется top-level WPF-окно с владельцем Explorer и нижним Z-order. Снимок настоящего рабочего стола подтвердил отрисовку; проверка мышью также прошла. Добавлена отдельная проверка desktop pixels.

Создание блока доступно выделением области левой или правой кнопкой с командой «Создать блок здесь». Реальный правый drag прошёл через hook и открыл меню; отдельная GUI-проверка подтвердила создание блока и точное сохранение выбранного прямоугольника после исправления промежуточных координат WPF при запуске.

Обычный smoke-тест больше не отправляет Win+D. Режим с переключением рабочего стола доступен только с явным параметром `--desktop-visual-test`.

Проверена автономная сборка `artifacts/MyFences/MyFences.exe`.

- Release-сборка: 0 ошибок, 0 предупреждений.
- 10 автоматических проверок: новая конфигурация; JSON с Unicode, отрицательными координатами и roll-up; резервная копия; восстановление повреждённого JSON; перенос файла без потери содержимого; конфликт имён; вложенное выделение; повторный drop в тот же блок; защита родительской папки хранилища; системная иконка.
- GUI: owner HWND Explorer, top-level WS_EX_TOOLWINDOW, roll-up и восстановление высоты, физический импорт и обновление сетки через FileSystemWatcher, скрытие/показ HWND, сохранение состояния.
- Настоящее shell-меню создано и открыто, затем отменено тестом без выбора команды.
- Win+D: контейнер остался видимым и доступным для hit-test; повторная комбинация восстановила окна приложений.
- Тесты выполнялись на изолированных временных данных и не перемещали файлы пользователя.

Отчёты: `artifacts/MyFences/self-test-results.txt`, `artifacts/MyFences/smoke-results.txt`.
Снимок WPF-окна: `artifacts/MyFences/smoke-window.png`.

Проверка Win+D относится к текущей системе. Отдельно не проверены другие сборки Windows, смешанные DPI нескольких мониторов, перезапуск Explorer и ручные команды сторонних shell-расширений.
